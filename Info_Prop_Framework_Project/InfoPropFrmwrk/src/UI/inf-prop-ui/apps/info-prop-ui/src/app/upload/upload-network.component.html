Recommended Folder Structure

📁 your-network-project/
├── 📄 network.edges                    ← Shared by ALL scenarios
├── 📄 node-mapping.txt                 ← Optional: Node labels
├── 📁 baseline/                        ← Scenario 1 (Float data)
│   ├── 📄 nodepriors.json             ← Float values
│   └── 📄 linkprobs.json              ← Float values (same type!)
├── 📁 conservative/                    ← Scenario 2 (Interval data)
│   ├── 📄 nodepriors.json             ← Interval values
│   └── 📄 linkprobs.json              ← Interval values (same type!)
├── 📁 uncertain/                       ← Scenario 3 (P-Box data)
│   ├── 📄 nodepriors.json             ← P-Box values
│   └── 📄 linkprobs.json              ← P-Box values (same type!)
├── 📁 capacity-normal/                 ← Flow scenario 1
│   └── 📄 capacities.json
└── 📁 cpm-project/                     ← CPM scenario 1
    └── 📄 cpm-inputs.json
💡 Key Points:
  • Edge source is flexible - Use one shared root .EDGES file, or provide per-scenario .EDGES files
  • Inference fallback - If no .EDGES file is supplied, backend can infer edges from supported analysis inputs
  • Scenario consistency - Within each reachability scenario, nodepriors and linkprobs must use the same data type
  • Automatic detection - System automatically detects data type from JSON "data_type" field
  • Flexible naming - You can use ANY scenario folder names - no restrictions!
  • Multiple scenarios - Upload as many scenarios as needed for different analyses
  • Mixed types allowed - Different scenarios can have different data types (Float, Interval, P-Box)

    └── 📄 grid-graph-cpm-inputs.json          ← Time and cost analysis
🏷️ Data Type Examples in JSON:
  • Float64: {{ '{' }}"data_type": "Float64", "nodes": {{ '{' }}"1": 0.9{{ '}' }}{{ '}' }}
  • Interval: {{ '{' }}"data_type": "Interval", "nodes": {{ '{' }}"1": {{ '{' }}"lower": 0.8, "upper": 0.95{{ '}' }}{{ '}' }}{{ '}' }}
  • P-Box: {{ '{' }}"data_type": "pbox", "nodes": {{ '{' }}"1": {{ '{' }}"type": "pbox", ...{{ '}' }}{{ '}' }}{{ '}' }}
