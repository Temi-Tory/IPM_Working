\chapter*{Abstract}
\addcontentsline{toc}{chapter}{Abstract}

Complex processes and infrastructures require careful planning and monitoring. Be it at the design stage or during normal operations to eventual decommissioning, civil infrastructure systems require specialized modelling and analysis tools across their entire lifecycle. Through all of this, design decisions propagate through the system in ways that are difficult to predict without a unified analytical view of the system. Operators, designers, and planners working on the same process at the same time may be asking fundamentally different questions of it. In these systems, performance objectives and success criteria demand different combinations of tools.

This usually leads to separate representations of the same system are maintained in parallel, with little overlap, shaped by the specific metadata each use case requires. As systems scale in size and complexity, the diversity of these analysis needs continues to grow while fragmentation further increases.

Rarely does a framework exist that uses a single shared model of the network to support multiple analysis objectives. This work presents such a framework: an integrated multi-algorithm system for performance analysis of flow-oriented processes on directed acyclic graph (DAG) networks, built around a single shared network model that supports multiple analysis objectives without redefining the underlying network.

The Information Propagation Framework is a collection of exact propagation algorithms: probability propagation with exact belief propagation over DAGs including structural handling of convergent subgraphs via diamond decomposition; a generalised Critical Path Method that supports configurable operator combinations for scheduling and cost analysis; and a capacity analysis pipeline covering maximum flow, sensitivity analysis, failure impact, and structural vulnerability.

In this work, the propagation algorithms are parametric over three possible uncertainty representations (deterministic values, interval bounds, and probability boxes) to allow users the flexibility to run any of the available analysis endpoints under different assumptions about input uncertainty. Multiple case studies are presented to demonstrate the efficiency and accuracy of all implemented algorithms across networks of varying size and complexity.

The framework is implemented as an open-source Julia package with a codebase designed to be adapted or extended for specific use cases. To reduce the barrier to adoption for users less familiar with Julia or scientific programming, the framework is also delivered as a graphical web application. The front-end operates on user-owned local data and serves as a practical profiling tool for evaluating design robustness, identifying resource bottlenecks, assessing scheduling risk, and tracing how design decisions propagate through downstream constraints across different scenarios and metrics.
