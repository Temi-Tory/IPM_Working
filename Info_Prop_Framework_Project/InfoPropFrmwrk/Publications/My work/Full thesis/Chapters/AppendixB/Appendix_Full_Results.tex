This appendix holds the complete validation tables that the toolkit chapters summarise but
do not reproduce in full, and a map from every figure and table in the thesis to the
script and data file that produced it. Every network named here is specified in
Appendix~\ref{app:network-specs}. The raw logs, per-graph results, request and response
JSON, and the scripts themselves are archived in the thesis data repository
(\S\ref{sec:appB-map} gives the DOI and the path of each artefact).

\section{Timing convention}
\label{sec:appB-timing}

Every runtime reported in this thesis is wall-clock, measured on a single core, on the
\emph{second} call within a warm process --- a discarded warm-up run precedes every
measurement, so no figure includes just-in-time compilation. Where a comparison is made
against another method, the ratio of run counts is reported rather than raw seconds
wherever the comparison would otherwise depend on the machine. This convention is stated
once here and referenced, not restated, by each chapter.

\section{Probability propagation}
\label{sec:appB-prob}

\subsection{Exactness on the 129-graph corpus}

The probability toolkit was checked against an independently built reduced ordered
binary decision diagram oracle on the full corpus of 129 synthetic graphs
(Appendix~\ref{sec:appA-corpus}). \textbf{All 129 agree exactly}, worst absolute deviation
$1.1 \times 10^{-16}$ for point beliefs and $2.78 \times 10^{-16}$ for interval bounds,
both at machine precision, and none changed against the pre-existing recorded results
(tolerance $10^{-9}$). The corpus is reconstructed exactly from recorded seeds; its node priors lie
in a range that never places a non-source node at exactly 0 or 1, so it does not exercise
the degenerate-prior path. Script:
\filepath{corpus/random-and-mutated/rerun\_129\_corpus.jl}; per-graph results:
\filepath{rerun_129_corpus_results.csv}.
