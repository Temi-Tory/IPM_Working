Recommended Folder Structure

📁 your-network-project/
├── 📄 network.edges                    ← Shared by ALL scenarios
├── 📄 node-mapping.txt                 ← Optional: Node labels
├── 📁 baseline/                        ← Scenario 1 (Float data)
│   ├── 📄 nodepriors.json             ← Float values
│   └── 📄 linkprobs.json              ← Float values (same type!)
├── 📁 conservative/                    ← Scenario 2 (Interval data)
│   ├── 📄 nodepriors.json             ← Interval values
│   └── 📄 linkprobs.json              ← Interval values (same type!)
├── 📁 uncertain/                       ← Scenario 3 (P-Box data)
│   ├── 📄 nodepriors.json             ← P-Box values
│   └── 📄 linkprobs.json              ← P-Box values (same type!)
├── 📁 capacity-normal/                 ← Flow scenario 1
│   └── 📄 capacities.json
└── 📁 cpm-project/                     ← CPM scenario 1
    └── 📄 cpm-inputs.json
💡 Key Points:
  • One edges file - All scenarios share the same network structure
  • Scenario consistency - Within each scenario, all files must use the same data type
  • Automatic detection - System automatically detects data type from file content
  • Multiple scenarios - You can have unlimited scenarios of any type
  • Descriptive naming - Use meaningful names like "Breakdown 214", "main scenario", "Degraded"
📋 Example with Multiple Scenarios:
📁 network-analysis-project/
├── 📄 network.edges                    ← Shared structure
├── 📁 main scenario/                   ← Primary scenario (system detects: Float)
│   ├── 📄 nodepriors.json             ← Contains: {{ '{' }}"node1": 0.8, "node2": 0.6{{ '}' }}
│   └── 📄 linkprobs.json              ← Contains: {{ '{' }}"(1,2)": 0.9, "(2,3)": 0.7{{ '}' }}
├── 📁 Breakdown 214/                   ← Descriptive scenario name (system detects: Interval)
│   ├── 📄 nodepriors.json             ← Contains: {{ '{' }}"node1": [0.7, 0.9]{{ '}' }}
│   └── 📄 linkprobs.json              ← Contains: {{ '{' }}"(1,2)": [0.8, 0.95]{{ '}' }}
├── 📁 Degraded/                        ← System failure scenario (system detects: P-Box)
│   ├── 📄 nodepriors.json             ← Contains: complex uncertainty data
│   └── 📄 linkprobs.json              ← Contains: complex uncertainty data
├── 📁 system overall capacity/         ← Flow analysis scenario
│   └── 📄 capacities.json             ← Contains: {{ '{' }}"(1,2)": 100, "(2,3)": 80{{ '}' }}
└── 📁 cpm/                             ← Time/cost analysis scenario
    └── 📄 cpm-inputs.json             ← Contains: time and cost data
