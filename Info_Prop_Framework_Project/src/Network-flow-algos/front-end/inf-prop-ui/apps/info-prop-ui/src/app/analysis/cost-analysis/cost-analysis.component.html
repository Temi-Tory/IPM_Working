Critical Cost Path
Critical Path Cost = max(Path Costs)

The critical cost path represents the most expensive sequence of activities that determines the minimum project budget.

 Cost Optimization
Optimization Potential = Critical Cost - Node Cost

Cost optimization represents the amount by which an activity's cost can be reduced without affecting the total project budget.

 Budget Allocation
Budget Share = (Node Cost / Total Budget) × 100%

Budget allocation focuses on optimal resource distribution while maintaining cost efficiency and project constraints.
