Core Framework
Utilization(N) = Flow(N) / Capacity(N)

Each node's utilization represents the ratio of current flow to maximum capacity, identifying bottlenecks and unused capacity in the network.

 Flow Conservation
Σ Flow_in(N) = Σ Flow_out(N) + Demand(N)

Network flow must be conserved at each node, with inflow equal to outflow plus any node demand or supply.

 Bottleneck Detection
Bottleneck: Utilization(N) ≥ 0.95

Nodes operating at or near capacity (≥95% utilization) are identified as potential bottlenecks that may limit network performance.
