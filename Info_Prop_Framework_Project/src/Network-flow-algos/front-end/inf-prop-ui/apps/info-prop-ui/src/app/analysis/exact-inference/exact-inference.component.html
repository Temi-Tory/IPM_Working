Core Framework
Belief(N) = Prior(N) × P(N receives ≥1 signal)

Each node's belief combines its intrinsic prior probability with the probability of receiving at least one signal from source nodes through the DAG structure.

 Inclusion-Exclusion
P(A ∪ B ∪ C) = S₁ + S₂ + S₃ - S₁S₂ - S₁S₃ - S₂S₃ + S₁S₂S₃

For join nodes with multiple independent paths, we use inclusion-exclusion to avoid double-counting signal probabilities.

 Diamond Enumeration
Result = Σ P(state) × f(state, join_node)

Complex dependency structures (diamonds) are handled by conditional enumeration over all possible states of conditioning nodes.
